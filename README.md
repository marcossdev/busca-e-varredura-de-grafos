# Busca e Varredura de Grafos - DFS e BFS

Trabalho da disciplina Teoria dos Grafos sobre busca e varredura dos grafos com os algoritmos DFS e BFS.

## Como executar

```sh
# Criar o ambiente virtual (venv)
python -m venv venv

# Ativar o ambiente virtual
# No Linux/macOS:
source venv/bin/activate
# No Windows (PowerShell):
.\venv\Scripts\Activate.ps1
# No Windows (CMD):
.\venv\Scripts\activate.bat

# Instalar as dependências do script
pip install -r requirements.txt

# Executar o script
python main.py
```
